# 🌟 Mariana's ESL Learning Hub & Family Homework

Interactive, web-based English as a Second Language (ESL) learning suite tailored for **Mariana** (CEFR Level B1–B2), featuring real-life idioms, collocations, family character traits, and interactive matching homework.

## ⚙️ Enabling GitHub Pages (One-Time Setup)

To publish these pages so anyone can view them online:
1. Open this repository on GitHub: [`https://github.com/log210788/helpingkids`](https://github.com/log210788/helpingkids)
2. Go to **Settings** (top tab).
3. In the left sidebar, click **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/ (root)`
5. Click **Save**.
6. Wait 1–2 minutes, and your site will be live at:  
   👉 **`https://log210788.github.io/helpingkids/`**
